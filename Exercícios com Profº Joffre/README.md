# Exercícios com Profº Joffre

Resoluções em Python da atividade de avaliação do 4º bimestre. Cada exercício está em um arquivo independente, de `ex01.py` a `ex10.py`, e pode ser executado, por exemplo, com:

```bash
python ex01.py
```

Autor informado no cabeçalho: **Matheus Crepaldi**.

## Conteúdo

1. Potências de 3, calculadas com repetição.
2. Crescimento e total de grãos em 64 quadros.
3. Somatório, média e quantidade de valores não negativos.
4. Área de cômodos e área total da residência.
5. Quociente inteiro por subtrações sucessivas.
6. Menor, maior e média de 20 temperaturas.
7. Vetor de somatórios de 1 até cada elemento de A.
8. Transformação dos elementos de A segundo o índice.
9. Validação e junção de dois vetores.
10. Quantidade e percentual de elementos ímpares.
